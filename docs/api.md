callable and the first sentence of its docstring. The docstrings hold the
full contracts: `help(marl_bgs.evaluate)` in Python, or your editor's hover.

Website: https://marl-battlegrounds.com/#api

Generated by `scripts/dev/export_api_reference.py`; do not edit by hand.

## Commands

Every command returns 0 on success, 1 when the work fails for a stated reason (printed to standard error), 2 for bad arguments and 130 when interrupted.

| Command | What It Does |
|---|---|
| `python -m marl_battlegrounds train` | Run or resume a declared PPO, QMIX or PQN-VDN experiment |
| `python -m marl_battlegrounds runs` | Find saved training runs and study cases |
| `python -m marl_battlegrounds analyze-training` | Plot saved training and validation results |
| `python -m marl_battlegrounds reselect-checkpoint` | Write a separate checkpoint decision from saved validation |
| `python -m marl_battlegrounds extend-training` | Continue a full learner checkpoint into a new child run |
| `python -m marl_battlegrounds study` | Run or inspect a declared training study |
| `python -m marl_battlegrounds study run` | Run the study in the foreground |
| `python -m marl_battlegrounds study start` | Start the study in the background |
| `python -m marl_battlegrounds study status` | Read saved progress without starting a numerical backend |
| `python -m marl_battlegrounds study stop` | Ask the study's exact live processes to stop |
| `python -m marl_battlegrounds evaluate` | Evaluate two frozen methods |
| `python -m marl_battlegrounds canonical` | Compare the released field, optionally with a challenger |
| `python -m marl_battlegrounds tournament` | Run an entrant list or saved field |
| `python -m marl_battlegrounds select-population` | Freeze the declared initial population from saved tournament results |
| `python -m marl_battlegrounds models` | Explicit asset preparation and cache cleanup |
| `python -m marl_battlegrounds models download` | Download released models by name, or inspect and confirm missing tournament asset downloads |
| `python -m marl_battlegrounds models clean` | Remove only selected cache digests; stop other cache writers first |
| `python -m marl_battlegrounds entry` | Make, check and submit a leaderboard entry |
| `python -m marl_battlegrounds entry new` | Write a starter entry in a new folder and make it a Git repository |
| `python -m marl_battlegrounds entry check` | Check an entry's commit the way we will: clone, install, a 15-minute training test, loading, export and play limits |
| `python -m marl_battlegrounds entry submit` | Open the submission form, filled in, for a checked commit |
| `python -m marl_battlegrounds replay` | Open an existing replay |

# Code Of Conduct

MARL-BattleGrounds follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: treat everyone with respect, and help keep this project a
harassment-free place for everyone.

It applies in all project spaces: issues, pull requests, reviews and every
other place where people take part. It also applies when someone speaks for
the project in public.

To report a problem, email t.hawili@sms.ed.ac.uk. Every report is reviewed
promptly and fairly, and the privacy of the person who reports it is respected.

# MARL-BGs Emblem

These images are the MARL-BGs emblem from the project's own logo files. Each
one is the emblem alone, cropped to its content, centred in a square and
resized. Pixels that were almost transparent were cleared, so no faint haze
shows on a dark panel.

| File | Size | Use |
| --- | --- | --- |
| `marl-bgs-emblem-32.webp` | 32 x 32 px | Small browser tab icon |
| `marl-bgs-emblem-64.png` | 64 x 64 px | Browser tab icon, and the fallback for browsers without WebP |
| `marl-bgs-emblem-64.webp` | 64 x 64 px | Header emblem |
| `marl-bgs-emblem-128.webp` | 128 x 128 px | Header emblem on high-density screens |

Rules for using them:

- They belong to the page frame only: the header, the title card and the tab
  icon. They are never drawn inside the arena.
- Exported PNG images of the arena carry no brand mark. The export refuses
  raster images, so these files cannot reach an export by accident.
- The local server lists every file here as a required browser asset, and the
  Python wheel ships this whole folder.

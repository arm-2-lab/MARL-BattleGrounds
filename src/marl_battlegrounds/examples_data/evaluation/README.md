# Saved Evaluation Demonstration

These unchanged records come from a public `evaluate` software check: two
paired two-tick games, all ten agents active, custom counter Systems whose
actions use the Random policy, one full record and two replays. The source test
is `test_saved_system_pair_routes_0` in the evaluator workflow checks. These
records demonstrate file reading and metric charts, not trained behavior or
statistical competence. Read the uncertainty limits reported by the API.

The original run identity, source records, schema and replays are preserved.
Opening the analysis notebook starts no experiment. Its cells read this bundle
or your chosen exact saved result directory without changing either.
